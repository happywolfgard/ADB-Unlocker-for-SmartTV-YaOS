# ADB TV Enabler (YaOS / Android TV / CVTE)

Легковесная (34 КБ) утилита для Android TV и Яндекс ТВ (YaOS), разработанная специально для решения проблемы закрытого порта `5555` и активации отладки по ADB по локальной сети Wi-Fi.

Подходит для телевизоров на платах **CVTE**, **MStar**, **MediaTek** (Haier, Doffler, Harper, BBK, Яндекс ТВ, Салют ТВ и др.), где производитель скрывает стандартные настройки Android и блокирует порт 5555.

---

## 🚀 Возможности

1. **Автоматический цикл активации ADB (порт 5555):**
   - Выполняет серию системных команд (`su`, `setprop service.adb.tcp.port 5555`, `ctl.restart adbd`, `Settings.Global`) до тех пор, пока сокет `127.0.0.1:5555` не станет отвечать на подключения.
   - Живой мониторинг статуса порта и наличия Root (`su`).

2. **🔍 Встроенный сканер скрытых сервисных меню:**
   - Сканирует все установленные системные компоненты телевизора.
   - Находит и выводит прямо на экран список реальных сервисных и фабричных меню (`factory`, `engineer`, `cvte`, `mstar`, `service`, `design`) в виде кнопок для прямого запуска с пульта.

3. **⚙️ Быстрые переходы в скрытые настройки Android:**
   - Прямой вызов оригинального системного экрана **«Для разработчиков»** (минуя урезанную оболочку лаунчера).
   - Вызов экрана **«Беспроводная отладка»** (Android 11+).
   - Вызов настроек изображения/экрана (для ввода сервисных комбинаций пульта).

4. **📺 100% адаптация под пульт телевизора (D-Pad):**
   - Крупные элементы, высокая контрастность, яркая подсветка активного фокуса при навигации стрелками.

## 📥 Установка и использование

1. Скачайте файл **`AdbTvEnabler.apk`** из раздела [Releases](../../releases) (или скопируйте из корня проекта).
2. Запишите APK на любую USB-флешку.
3. Вставьте флешку в телевизор, откройте встроенный проводник/медиаплеер и установите приложение.
4. Запустите **ADB TV Enabler** на телевизоре:
   - Нажмите первую кнопку **«🚀 Цикл команд для включения ADB (5555)»**.
   - Дождитесь, пока статус станет зеленым (**ОТКРЫТ! ✅**).
   - Если статус не меняется, нажмите **«⚙️ Меню разработчика чистого Android»** и включите отладку вручную.

---

## 💻 Подключение с компьютера

В терминале (PowerShell / CMD):
```powershell
adb connect <IP_ВАШЕГО_ТЕЛЕВИЗОРА>:5555
adb devices
```

Чтобы порт 5555 не закрывался после перезагрузок телевизора, закрепите его командой:
```powershell
adb shell setprop persist.adb.tcp.port 5555
```

## 🛠 Сборка из исходников

Для сборки не требуется тяжелый Android Studio. Достаточно наличия Android SDK (build-tools + platform) и Java 17+.

Сборка выполняется одной командой:
```powershell
powershell -ExecutionPolicy Bypass -File .\build_apk.ps1
```
Скрипт автоматически скомпилирует ресурсы через `aapt2`, код через `javac`, сгенерирует DEX через `d8`, выровняет через `zipalign`, подпишет отладочным сертификатом через `apksigner` и положит готовый `AdbTvEnabler.apk` в корень.
